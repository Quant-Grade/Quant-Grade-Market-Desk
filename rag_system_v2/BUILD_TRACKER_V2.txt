=== ARCHITECTURE DECISIONS (V2 vs V1) ===
---------------------------------------------------------------------------
V1 (preserved in rag_system/):
  - FAISS flat index
  - all-MiniLM-L6-v2 embeddings
  - Flat chunking (512 tokens)
  - Single index.py module

V2 (this build - rag_system_v2/):
  - Qdrant local embedded (persistent ./data/qdrant)
  - bge-small-en-v1.5 embeddings (better for technical/crypto docs)
  - Parent-child chunking (parent: 900-1200 tokens, child: 200-350 tokens)
  - Separate modules: index_bm25.py, index_qdrant.py, merge_rrf.py
  - Explicit RRF fusion with logged scores
  - Citation verification (verify.py)
  - Full evaluation harness (eval.py)
  - Prompt injection detection + fail-closed router

Key thresholds (MUST BE CALIBRATED via eval harness):
  - T_DIRECT_CONFIDENCE: 0.75 (initial, tune with eval)
  - T_RETRIEVE_CONFIDENCE: 0.50 (initial, tune with eval)
  - T_CLARIFY_CONFIDENCE: 0.35 (initial, tune with eval)
  - T_REFUSE_THRESHOLD: 0.25 (below this = refuse)
  - T_RERANK_SCORE_HIGH: 0.70 (skip rerank if both top scores above)
  - T_EVIDENCE_COUNT_MIN: 2 (need at least 2 chunks above threshold)
  - T_SCORE_GAP_SUSPICIOUS: 0.30 (if gap > this, check for ambiguity)
